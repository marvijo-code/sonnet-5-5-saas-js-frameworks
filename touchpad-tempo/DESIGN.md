# Design decisions

Touchpad Tempo looks like a pool deck after dark: deep lane-water teal panels, with the yellow of a timing touchpad reserved for the one thing coaches read first, the time. Every time is set in tabular monospace so splits line up digit by digit like a scoreboard, while headings use a warm serif to give the tool a coach's-notebook feel instead of a dashboard-template one. A lane-rope stripe under the header and small split bars on every race turn the domain's own objects (ropes, splits, pacing) into the visual language. Colour carries meaning only: yellow for best or primary, green for faster or qualified, coral for slower, amber for within 2% of a cut. Cards stack on phones and settle into a list-plus-form layout on desktop so a coach can log a race poolside on a phone.
